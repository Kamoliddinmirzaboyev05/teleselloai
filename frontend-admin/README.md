# Frontend Admin

Next.js CRM admin panel for Telegram AI Sales Agent.

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open `http://localhost:3000`.

The frontend expects the backend at `NEXT_PUBLIC_API_URL`, defaulting to
`http://localhost:8000`.

## Scripts

```bash
npm run lint
npm run build
```
